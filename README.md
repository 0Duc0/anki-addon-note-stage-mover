# Quick Note Mover

Private archive of the installed add-on source and a portable installation package.

Install the file from `dist/` using Anki Desktop: Tools → Add-ons → Install from file, then restart Anki.

Personal configuration, user_files, logs, backups and collection data are excluded. Defaults are used on a new computer. Windows compatibility is not runtime-tested; this archive does not claim otherwise.

Original author, license and attribution notices are retained in source/. Third-party add-ons remain the work of their respective authors. This archive is not an upstream release.
